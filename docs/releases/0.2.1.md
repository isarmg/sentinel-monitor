# Sentinel Monitor 0.2.1

修复固定 MediaMTX 1.20.0 的默认监听边界：显式关闭产品未使用的 RTMP、SRT 和 MoQ，防止额外监听及 MoQ 在工作目录生成 `auto.key`/`auto.crt`。保留受支持的 RTSP、HLS、WebRTC、API、metrics 和 playback。

本版重新绑定配置摘要、当前产品/凭据身份、Web 静态合同和物理发行路径。只接受本版当前合同，不提供 0.2.0 数据迁移、旧读取器、旧路径或兼容层；请按本版文档进行新的部署。

Server Foundation 仍锁定 0.6.0 与完整 revision，Web 包仍使用不可变 tarball。正式发布以精确提交 CI、真实固定 MediaMTX 配置验收和完整发行归档验收为准。

0.2.0 已发布标签及制品保留用于审计，但不再作为推荐正式版本。此前的回环 smoke 为避免开放端口而用环境变量关闭额外协议，因此未证明发行配置自身关闭这些默认服务；本版新增原始配置回归补齐该缺口。
